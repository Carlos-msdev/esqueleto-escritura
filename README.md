# Esqueleto de escritura

Herramienta de la Facultad de Educación (Universidad de los Andes) para que estudiantes de posgrado construyan, paso a paso, el esqueleto de escritura de su trabajo de investigación y lo descarguen en Word.

- Todo funciona en el navegador: no requiere cuentas ni servidor.
- El avance se guarda automáticamente en el navegador de cada estudiante.
- Para actualizar la herramienta, reemplaza `index.html`.
